# Security Repository Template

This repository template contains reusable security baselines, host hardening guidance, audit configuration, malware scanning standards, and security onboarding checklists.

## Owns

- security baselines
- hardening automation references
- audit rules
- scanner configuration guidance
- node onboarding checks

## Does Not Own

- application source code
- production deployment overlays
- Terraform state
- real incident evidence

## Reference Blueprints

- [Wazuh/SIEM Integration Blueprint](wazuh/README.md) - discovery, WAF log integration, detection engineering, triage, ownership, and sizing guidance.
