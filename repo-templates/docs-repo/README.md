# Documentation Repository Template

This repository contains shared documentation for the organization/client.

## Contents

- architecture decisions
- diagrams
- onboarding guides
- operational runbooks
- incident response docs
- environment inventory
- access model
- security model

This repository may be shared more broadly than infrastructure repositories.

## Policy As Code

Documentation repositories should use machine-verifiable checks for Markdown style, local links, schemas, public-safety markers, required decision-record fields, and generated navigation where practical. These checks protect documentation quality; they do not replace technical review or approval of architecture decisions.

Never encode private customer identifiers, evidence, contacts, or exception approvals into public documentation fixtures.
